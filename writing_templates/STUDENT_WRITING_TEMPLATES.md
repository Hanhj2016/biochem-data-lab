# Student Writing Templates

Use these templates after finishing a notebook, mini-project, or challenge. Keep all wording cautious: BioChem Data Lab uses synthetic educational data only.


---

## Figure Caption Template

```text
Figure [number]. [Measurement] was compared across [groups or conditions].
[Bars/points/lines] represent [mean values / individual samples].
Error bars represent [SD or SEM].
The main observed pattern was [main observation].
This result should be interpreted cautiously because [limitation].
```

### Example

```text
Figure 1. Cell viability was compared across increasing concentrations of DrugA and DrugB in a synthetic dose-response dataset. Points represent mean cell viability across three replicates, and error bars represent SEM. DrugA showed a lower mean viability at higher concentrations than DrugB. Because the dataset is synthetic and small, the result should be interpreted as a learning example rather than real drug efficacy evidence.
```

## Results Paragraph Template

```text
[Measurement] was analyzed across [groups/conditions].
The [control/baseline] group showed [summary].
The [treatment/comparison] group showed [summary].
Overall, the data suggest [cautious observation].
However, [limitation], so additional validation would be needed.
```

### Useful Phrases

```text
The data suggest...
The observed pattern is consistent with...
The result should be interpreted cautiously...
Additional replicates would be needed...
This synthetic dataset is useful for practice but not for real conclusions.
```

## Limitations Template

### Common Limitations

```text
small sample size
synthetic data
limited number of replicates
possible outliers
missing values
no independent validation
no orthogonal assay
no normalization
no post-hoc testing
```

### Template

```text
This analysis has several limitations. First, [limitation 1]. Second, [limitation 2]. Third, [limitation 3]. Therefore, the result should be treated as a preliminary observation and not as a final biological conclusion.
```

## Academic Interview Prep Template

Use this after finishing a notebook or mini-project.

### One-Minute Project Explanation

```text
My project asked [biochemistry question]. I used [dataset] and analyzed [main variables]. I made [plot/table] to show [main pattern]. The key limitation is [limitation], so I would treat the result as a learning example and next check [next step].
```

### Questions To Practice

1. What was the biological question?
2. Why did you choose this analysis or graph?
3. What does the main figure show?
4. What does the dataset represent?
5. What are the limitations?
6. What would you check before trusting a similar result in a real lab?
7. How would you improve the analysis?
8. How did this project change how you think about biological data?

### Strong Answer Habits

- Start with the biological question.
- Name the dataset and variables.
- Explain the graph in plain language.
- Mention uncertainty or quality checks.
- Avoid overclaiming.
- End with a reasonable next step.

### Cautious Phrases

```text
In this synthetic dataset, the pattern suggests...
```

```text
This result is useful for practice, but it does not prove...
```

```text
Before making a stronger interpretation, I would check...
```
