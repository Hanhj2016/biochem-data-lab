# BioChem Data Lab: Quick Start Guide

**A Python + R + Jupyter starter kit for Biochemistry and life science data analysis**

## Purpose

This starter kit helps Biochemistry / Life Science students compare Python and R using the same Jupyter Notebook use cases.

The focus is:

```text
Biochemistry question
→ data table
→ statistics
→ graphical output
→ cautious academic interpretation
```

## Fastest Start

1. Install Miniconda or Anaconda.
2. Open Conda Navigator.
3. Create an environment named `biochem-stats`.
4. Install the required Python packages.
5. Launch Jupyter Notebook.
6. Open `notebooks/00_Setup_Check_Python.ipynb`.
7. Then open `notebooks/00_Setup_Check_R.ipynb`.

## Recommended First Notebook Pair

```text
notebooks/01_Enzyme_Activity_Python.ipynb
notebooks/01_Enzyme_Activity_R.ipynb
```

## Good First Goal

```text
Open a notebook.
Run cells.
See a table.
See a plot.
Explain what the result means.
```
