# AI Use Guide

## Purpose

AI tools can help students understand code, draft figure captions, and improve scientific explanations.

AI should support learning, not replace thinking.

---

# Good Uses of AI

## Explain Code

Prompt:

```text
Explain this Python code step by step for a Biochemistry student.
```

## Create a Figure Caption

Prompt:

```text
Write a cautious scientific figure caption for this plot. Mention what was measured, what the groups were, what the error bars represent, and one limitation.
```

## Review an Interpretation

Prompt:

```text
Review my interpretation. Tell me what is clear, what may be overclaimed, and what limitation I should add.
```

## Generate Study Questions

Prompt:

```text
Create 5 study questions based on this notebook about dose-response and cell viability.
```

---

# What Not to Upload

Avoid uploading:

```text
private lab data
patient data
confidential company data
unpublished research data
personal information
```

Use synthetic or public data for practice.

---

# How to Verify AI Output

Check:

```text
Does it match the data?
Does it overstate the conclusion?
Does it mention limitations?
Does it confuse SD and SEM?
Does it imply clinical meaning?
Does it invent details?
```

---

# Good Scientific Wording

Prefer:

```text
The synthetic data suggest...
The observed pattern is consistent with...
Additional validation would be needed...
```

Avoid:

```text
This proves...
This drug is effective...
This biomarker diagnoses...
```

---

# Useful AI Prompt Template

```text
You are helping a Biochemistry student learn data analysis.
Use cautious scientific language.
Do not overstate conclusions.
Mention limitations.
Do not give medical or clinical advice.

Here is the result:
[insert summary or figure description]

Please write:
1. Plain-English summary
2. Figure caption
3. Limitations
4. Study questions
```
