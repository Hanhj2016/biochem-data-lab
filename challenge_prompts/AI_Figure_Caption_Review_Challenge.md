# AI Figure Caption Review Challenge

## Mission

Act as a scientific communication reviewer checking AI-style figure captions for overclaims and safer wording.

## Dataset Path

```text
data/career_scenarios/ai_figure_caption_review.csv
```

## Tasks

1. Preview the figure context, AI caption, issue type, and safer caption columns.
2. Flag captions that make unsupported mechanism, clinical, diagnostic, efficacy, or function claims.
3. Compare each AI caption with the safer caption.
4. Create a review-status bar chart.
5. Write one revised caption that keeps the observation but removes the overclaim.

## Bonus Task

Create a small checklist students can use before accepting an AI-written figure caption.

## Expected Visual Output

A review-status bar chart and a table comparing AI captions with safer revisions.
