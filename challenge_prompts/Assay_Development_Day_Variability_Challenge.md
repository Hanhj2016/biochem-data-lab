# Assay Development Day Variability Challenge

## Mission

Act as an assay development trainee checking whether two synthetic assay days give similar dose-response summaries.

## Dataset Path

```text
data/career_scenarios/assay_development_day_variability.csv
```

## Tasks

1. Preview the assay day, compound, concentration, replicate, and cell viability columns.
2. Summarize mean viability by compound, concentration, and assay day.
3. Calculate or inspect the Day_2 minus Day_1 difference at matched concentrations.
4. Create a dose-response scatter or line plot colored by assay day.
5. Write a robustness note describing where day-to-day differences deserve review.

## Bonus Task

Choose one concentration where a day shift is visible and explain what metadata you would check in a real lab.

## Expected Visual Output

A dose-response plot split or colored by assay day, plus a day-delta summary table.
