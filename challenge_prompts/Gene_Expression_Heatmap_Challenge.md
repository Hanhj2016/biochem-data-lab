# Gene Expression Heatmap Challenge

## Mission

You are exploring toy gene expression patterns across control and treatment conditions.

## Dataset

```text
data/gene_expression/gene_expression_matrix_pca.csv
```

## Tasks

1. Create a heatmap.
2. Create a PCA-style sample map.
3. Identify which samples appear similar.
4. Explain why this is not a full RNA-seq workflow.

## Bonus

Write a short figure caption.
