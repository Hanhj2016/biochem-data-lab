# BioChem Data Lab: Optional Challenge Task Menu

**A Python + R + Jupyter starter kit for Biochemistry and life science data analysis**

## Purpose

These optional challenges add graphical representation and real-world-inspired thinking.

They are not required. Choose one challenge based on interest.

| Challenge | Topic | Visual Output | Difficulty |
|---|---|---|---|
| QC Detective | outlier detection | scatter + box plot | Easy / Medium |
| Dose Curve Pro | IC50-style fitting | fitted dose-response curve | Medium |
| Gene Heatmap | expression matrix | heatmap | Medium |
| PCA Explorer | sample patterns | PCA scatter plot | Medium / Hard |
| Figure Caption Writer | scientific communication | caption + figure | Easy |
| Mini Poster | presentation | Quarto-style poster | Medium |
| BioDose Feature Designer | capstone | feature plan | Medium |
