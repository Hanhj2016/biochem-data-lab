# Data Disclaimer

All datasets in BioChem Data Lab are synthetic and for educational use only.

They are not:

```text
real experimental data
clinical data
patient data
drug efficacy data
regulatory data
diagnostic data
```

The datasets are designed to help students practice:

```text
data loading
summary statistics
visualization
basic statistical testing
scientific interpretation
Python vs R comparison
```

## Important Boundaries

Do not use these datasets for:

```text
scientific conclusions
clinical decisions
medical advice
drug development decisions
regulatory submissions
publication claims
```

## AI and Interpretation Boundary

If AI tools are used to explain results, the output should be treated as a draft.

Students should verify:

```text
the original data
the statistical method
the figure
the biological interpretation
the limitations
```

## Suggested Wording for Reports

```text
This analysis uses synthetic data for learning purposes. The results are intended to practice data analysis and scientific interpretation, not to support real biological or clinical conclusions.
```
