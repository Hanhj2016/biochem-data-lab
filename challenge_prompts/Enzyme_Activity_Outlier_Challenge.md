# Enzyme Activity Outlier Challenge

## Mission

Review a synthetic enzyme activity dataset with one unusual treatment replicate and decide how to discuss it responsibly.

## Dataset Path

```text
data/enzyme_activity/enzyme_activity_outlier.csv
```

## Tasks

1. Preview the control and treatment enzyme activity values.
2. Create a dot plot or box plot showing individual samples.
3. Calculate mean, median, SD, SEM, and `n` for each group.
4. Identify the unusual value and describe why it should be reviewed.
5. Write a cautious interpretation that keeps the outlier visible.

## Bonus Task

Compare the group means and medians, then explain which summary is more affected by the unusual value.

## Expected Visual Output

A grouped dot plot or box plot with control and treatment on the x-axis and enzyme activity on the y-axis.
