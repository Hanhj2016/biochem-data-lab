# Research Assistant Replicate Log Challenge

## Mission

Act as a research assistant checking whether a synthetic enzyme-activity experiment has enough replicate support for cautious interpretation.

## Dataset Path

```text
data/career_scenarios/research_assistant_replicate_log.csv
```

## Tasks

1. Preview the condition, replicate, planned replicate, enzyme activity, and bench note columns.
2. Summarize mean activity, SD, SEM, and observed replicate count by condition.
3. Identify any missing replicate or high-variability condition.
4. Create a bar chart or dot plot showing condition means and uncertainty.
5. Write a short design-review note that separates observation from conclusion.

## Bonus Task

Suggest one practical way to improve the design before repeating the experiment.

## Expected Visual Output

A replicate-aware bar chart or dot plot with review status highlighted.
