# Academic Interview Prep Template

Use this after finishing a notebook or mini-project.

## One-Minute Project Explanation

```text
My project asked [biochemistry question]. I used [dataset] and analyzed [main variables]. I made [plot/table] to show [main pattern]. The key limitation is [limitation], so I would treat the result as a learning example and next check [next step].
```

## Questions To Practice

1. What was the biological question?
2. Why did you choose this analysis or graph?
3. What does the main figure show?
4. What does the dataset represent?
5. What are the limitations?
6. What would you check before trusting a similar result in a real lab?
7. How would you improve the analysis?
8. How did this project change how you think about biological data?

## Strong Answer Habits

- Start with the biological question.
- Name the dataset and variables.
- Explain the graph in plain language.
- Mention uncertainty or quality checks.
- Avoid overclaiming.
- End with a reasonable next step.

## Cautious Phrases

```text
In this synthetic dataset, the pattern suggests...
```

```text
This result is useful for practice, but it does not prove...
```

```text
Before making a stronger interpretation, I would check...
```
