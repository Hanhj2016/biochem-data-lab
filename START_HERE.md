# START HERE

## Welcome to BioChem Data Lab

**BioChem Data Lab** is a Python + R + Jupyter starter kit for Biochemistry and life science data analysis.

The goal is simple:

```text
Open a notebook.
Run cells.
See a table.
See a plot.
Explain what the result means.
```

You do not need to finish everything.

# Good First Session

```text
1. Open Jupyter Notebook.
2. Run 00_Setup_Check_Python.ipynb.
3. Run 01_Enzyme_Activity_Python.ipynb.
4. Look at the table and chart.
5. Write 2–3 sentences explaining the result.
```

That is already useful scientific data practice.
