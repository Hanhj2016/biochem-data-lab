# Bioinformatics Sequence Triage Challenge

## Mission

Act as a bioinformatics assistant summarizing short synthetic DNA sequences before making any biological interpretation.

## Dataset Path

```text
data/career_scenarios/bioinformatics_sequence_triage.csv
```

## Tasks

1. Preview the sequence ID, sequence, motif of interest, and expected review columns.
2. Calculate sequence length, GC content, and motif count.
3. Flag sequences with ambiguous bases such as N.
4. Create a GC-content bar chart by sequence ID.
5. Write a short triage note explaining what can and cannot be inferred from these summaries.

## Bonus Task

Add one column that explains whether each sequence should be treated as ready for summary or needing review.

## Expected Visual Output

A GC-content bar chart plus a sequence summary table with motif counts and review status.
