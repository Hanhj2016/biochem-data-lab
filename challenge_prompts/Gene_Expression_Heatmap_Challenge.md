# Gene Expression Heatmap Challenge

## Mission

Explore toy gene expression patterns across control, low-treatment, and high-treatment samples.

## Dataset Path

```text
data/gene_expression/gene_expression_matrix_pca.csv
```

## Tasks

1. Load the gene-by-sample expression matrix.
2. Create a gene-wise z-score heatmap.
3. Create a PCA-style sample map.
4. Identify which samples appear visually similar.
5. Explain why this is not a full RNA-seq workflow.

## Bonus Task

Write a short figure caption for the heatmap or PCA-style plot.

## Expected Visual Output

A heatmap with genes on one axis and samples on the other, plus an optional PCA-style scatter plot with sample groups separated by color.
