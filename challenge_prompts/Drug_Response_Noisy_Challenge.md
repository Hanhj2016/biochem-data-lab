# Drug Response Noisy Dataset Challenge

## Mission

Practice interpreting a synthetic dose-response dataset where replicate variability makes the pattern less certain.

## Dataset Path

```text
data/drug_response/drug_response_noisy.csv
```

## Tasks

1. Preview the dataset and count replicates per compound and concentration.
2. Calculate mean, SD, SEM, and `n`.
3. Plot the mean response and also show individual replicate points.
4. Compare the noisy pattern with what you would expect from a clean dataset.
5. Write a cautious interpretation that mentions variability.

## Bonus Task

Add a short note explaining how noisy replicates affect confidence in the visual trend.

## Expected Visual Output

A dose-response plot with visible replicate spread, ideally using points plus mean lines or error bars.
