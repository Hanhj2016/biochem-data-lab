# Drug Response Clear Dataset Challenge

## Mission

You are reviewing a synthetic compound screening dataset.

## Dataset

```text
data/drug_response/drug_response_clear.csv
```

## Tasks

1. Plot dose-response curves.
2. Calculate mean, SD, SEM by drug and concentration.
3. Identify which drug appears stronger at high concentration.
4. Write a cautious 3-sentence interpretation.
5. Generate a figure caption.

## Bonus

Suggest the next experiment.
