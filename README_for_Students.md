# BioChem Data Lab: README for Students

**A Python + R + Jupyter starter kit for Biochemistry and life science data analysis**

## What This Kit Is

BioChem Data Lab is a small collection of Jupyter Notebooks for exploring how Python and R can help with Biochemistry data.

You will practice:

- reading data
- calculating basic statistics
- making figures
- comparing Python and R
- interpreting results carefully

## Good First Step

Start here:

```text
notebooks/00_Setup_Check_Python.ipynb
```

Then try:

```text
notebooks/01_Enzyme_Activity_Python.ipynb
```

## If You Want to Compare R and Python

Try:

```text
notebooks/01_Enzyme_Activity_Python.ipynb
notebooks/01_Enzyme_Activity_R.ipynb
```

## If You Like Drug Testing

Try:

```text
notebooks/04_Dose_Response_Python.ipynb
```

## If You Like Bioinformatics

Try:

```text
notebooks/05_Gene_Expression_Python.ipynb
```

## Good Learning Goal

After a notebook, explain:

```text
What data did I use?
What calculation did I do?
What does the figure show?
What are the limitations?
```
