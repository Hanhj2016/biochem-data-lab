# QC Plate Batch Review Challenge

## Mission

Act as a beginner QC analyst reviewing synthetic plate-batch data before interpretation.

## Dataset Path

```text
data/career_scenarios/qc_plate_batch_review.csv
```

## Tasks

1. Preview the plate-batch dataset and identify the batch, sample type, plate region, and expected-range columns.
2. Summarize mean cell viability by batch, sample type, and plate region.
3. Flag wells or groups that fall outside the expected synthetic range.
4. Create a plot comparing batch summaries and review status.
5. Write a short QC note explaining what should be reviewed before interpretation.

## Bonus Task

Create a small table listing the review groups and a suggested lab-record check for each one.

## Expected Visual Output

A bar chart or heatmap-style summary showing plate-batch groups, mean viability, and review status.
