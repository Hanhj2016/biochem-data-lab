# Literature Abstract Challenge

## Mission

Turn a fictional scientific abstract into a structured academic summary.

## Dataset

```text
data/literature_abstracts/abstract_egfr_fictional.txt
```

## Tasks

1. Identify the research question.
2. Identify the drug target.
3. Identify the method.
4. Identify the main limitation.
5. Create 3 journal club questions.

## Bonus

Write a 3-slide presentation outline.
