# Drug Response Clear Dataset Challenge

## Mission

Explore a clean synthetic compound-screening dataset and practice cautious dose-response interpretation.

## Dataset Path

```text
data/drug_response/drug_response_clear.csv
```

## Tasks

1. Preview the dataset and identify the columns.
2. Calculate mean, SD, SEM, and `n` by compound and concentration.
3. Plot dose-response curves for each compound.
4. Identify which compound shows a larger decrease at high concentration.
5. Write a cautious 3-sentence interpretation.

## Bonus Task

Write a figure caption that explains the log-scale concentration axis and mentions that the data are synthetic.

## Expected Visual Output

An interactive line plot or scatter-line plot with concentration on the x-axis, mean cell viability on the y-axis, one line per compound, and SEM error bars if available.
