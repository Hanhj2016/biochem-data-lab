# Next Experiment Template

## Template

```text
A useful next experiment would be to [action].
This would help test whether [hypothesis].
The experiment should include [controls/replicates/conditions].
```

## Examples

```text
A useful next experiment would be to repeat the cell viability assay with more biological replicates and additional concentrations near the middle of the dose-response curve.
```

```text
A useful next experiment would be to verify the expression change using an independent method such as qPCR in a real experimental setting.
```
